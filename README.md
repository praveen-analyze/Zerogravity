# Zero Gravity Photography & Cinema

A luxury, aesthetic candid wedding photography and cinematography web platform built with **React**, **Tailwind CSS (v4)**, **GSAP Animations**, and **Native Lazy Loading** for [Zero Gravity Photography](https://zerogravity.photography/).

---

## ✨ Features

- **Luxury Editorial Design**: Tailored luxury dark color palette, refined typography (Cormorant Garamond & Outfit), and sleek glassmorphism.
- **GSAP Animation Suite**: Hero staggered text reveal, fluid floating badges, and smooth category filter transitions.
- **Lazy Loaded Image Gallery**: Progressive shimmer skeletons, blur-to-crisp transitions, fallback handling, and responsive masonry layout.
- **Interactive Lightbox Modal**: High-definition image previews with previous/next controls, keyboard navigation (`ArrowLeft`, `ArrowRight`, `Escape`), and image counter.
- **Signature Collections**: Traditional Weddings, Pre-Wedding & Outdoor, Haldi & Sangeet, Bridal & Groom Portraits, Destination Weddings, and Baby & Maternity Shoots.
- **Comprehensive Storytelling**: Real love story features (*Varalakshmi & Karthik*, *Ashikha & Surya*) with client quotes and highlights.
- **Reservation & Inquiries**: Interactive date availability form, modal consultation, and direct WhatsApp integration.
- **SEO & Performance Optimized**: Full OpenGraph, Twitter Cards, JSON-LD Schema (`schema.org/PhotographyBusiness`), critical image preloading, and asynchronous image decoding.

---

## 🛠 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 8](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [GSAP](https://gsap.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Hosting / Deployment**: [Vercel](https://vercel.com/)

---

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/praveen-analyze/Zerogravity.git
cd Zerogravity

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

---

## 🌐 Deploy to Vercel

1. Import this repository into [Vercel](https://vercel.com/).
2. Vercel automatically detects the **Vite** preset:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. Click **Deploy**!
